Command Help:

Usage: romi_run_task [OPTIONS] TASK_ID

  Execute a specific ROMI processing task on a dataset.

  Examples:
    romi_run_task Colmap /path/to/dataset
    romi_run_task AnglesAndInternodes /path/to/dataset --config my_config.toml

Positional arguments:
  task                  Name of the ROMI task to run. See the list of pre-defined tasks below.
  dataset_path          Path to the dataset to process (directory). You may use Unix pattern matching with "*"
                        and "?" to select a list of dataset.

Optional arguments:
  --config CONFIG       Pipeline configuration file (TOML) or directory. If a file, read the configuration from
                        it. If a directory, read & concatenate all configuration files in it. By default,
                        search a 'pipeline.toml' file in the selected dataset directory.
  --module MODULE       Library and module of the task. Use it if not available or different than defined in
                        `romitask.modules.MODULES`.
  --log-level {CRITICAL,DEBUG,INFO,NOTSET,WARNING,ERROR}
                        Level of message logging, defaults to 'INFO'.
  --dry-run             Use this to test the command-line by doing everything except calling the task(s).
  -h, --help            show this help message and exit

The list of pre-defined tasks is:
    CreateCharucoBoard, DetectCharuco, ExtrinsicCalibration, IntrinsicCalibration,
    Colmap, Undistort, Masks, Voxels, PointCloud, TriangleMesh, CurveSkeleton, Segmentation2D, SegmentedPointCloud, ClusteredMesh, OrganSegmentation, TreeGraph, AnglesAndInternodes, DummyTask, Clean.
